- Migration task must continue using DATABASE_URL with migration privileges.

## FIX 2 — Hard-fail production if unsafe backends are used

Problem:
Queue falls back to in-memory EventEmitter if QUEUE_BACKEND !== sqs. That is dangerous in AWS. Storage may also silently use local mode.

Required:
- In production/staging, hard-fail boot unless:
  - QUEUE_BACKEND=sqs
  - STORAGE_BACKEND=s3, if STORAGE_BACKEND exists / is used
- Validate through Zod env schema.
- Do not allow production to quietly use local/in-memory backends.
- Local/demo mode can keep safe fallbacks.

Validation:
- NODE_ENV=production + QUEUE_BACKEND missing/local fails at boot.
- NODE_ENV=production + QUEUE_BACKEND=sqs passes.
- Same for STORAGE_BACKEND if applicable.
